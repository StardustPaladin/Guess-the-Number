# Overview
I created a Guess the Number game to improve my Java programming skills and learn how different parts of a program work together. The program allows a player to choose a difficulty level, guess a randomly generated number, and receive feedback on whether each guess is too high or too low. It also keeps track of game statistics.

My purpose for writing this software was to get more comfortable with Java syntax and practice using classes, interfaces, methods, loops, conditionals, and collections. This project helped me understand how to organize code into separate files and how to use an interface with the implements keyword. It also gave me practice handling user input and making a program interactive.

[Guess the Number](https://youtu.be/Kod-bUnx-z0)

# Development Environment
I used Visual Studio Code to write, organize, compile, and run my Java program. I used the integrated terminal to compile the source files and run the game so that the player could enter guesses and interact with the program.

I used Java as the programming language. The program uses Java's built-in libraries, including java.util.Scanner for reading user input, java.util.Random for generating the secret number, and java.util.ArrayList for storing game information. I also used classes and an interface to organize the program and make the code easier to understand and maintain.
